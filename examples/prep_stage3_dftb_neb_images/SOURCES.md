# 反応経路の像ごとの一点計算の実行 — DFTB+ 25.1、mio-1-1 (2026-09-12)

## 何の例か

エタノールではなくエタン (ASE の `molecule("C2H6")`、ASE 3.29.0) を始状態にし、片方の CH3 を C–C 軸のまわりに 60° 回した構造を
終状態にして、ASE の `NEB.interpolate(method="idpp")` で中間の像を 5 個作り、7 個の像それぞれで DFTB+ の一点計算をしたもの。
`adit-gen spec.json out/ --neb start.xyz end.xyz --images 5 --neb-mode images` (`src/adit/neb_setup.py`) と同じ処理を API で呼んで生成し、
`adit-analyze out/ --scan` で表にした。

- これは NEB の最適化ではない (補間した位置のまま、エネルギーだけを計算する)。計算コードの NEB (VASP・QE neb.x・CP2K BAND) は
  `--neb-mode native` で書く (手元に VASP が無く、QE と CP2K の NEB は短い実行に収まらないので、この日は実行していない)
- idpp は原子間の距離を補間するので、中間の像は剛体の回転にはならない
- 始状態は ASE の分子の座標のままで、DFTB+ で最適化していない (始状態の力の最大値 0.82 eV/Å)
