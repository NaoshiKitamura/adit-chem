# 弾性定数 (歪みを振った一括生成 + 応力の直線の当てはめ) の実行 — DFTB+ 25.1、mio-1-1 (2026-09-12)

## 何の例か

ダイヤモンドの立方晶セル (C 8 原子、ASE の `bulk("C", "diamond", a=3.567, cubic=True)`、格子は緩和していない) に、Voigt の成分 1 (xx) と
4 (yz、工学歪み) それぞれ ±0.005 の歪みを与えた 4 個と、歪みなし (e0) の 1 個を DFTB+ の一点計算 (k 点 4×4×4、SCC) にしたもの。
`adit-gen spec.json out/ --elastic=-0.005,0.005 --elastic-components 1,4` (`src/adit/elastic_setup.py`) と同じ処理を API で呼んで生成し、
実行したあと `python elastic_collect.py` で集めた。

- 一点計算なので、原子を動かさない値 (clamped-ion) である
- 成分ごとに、歪みなしを含む 3 点で応力 σ_i(δ) に最小二乗の直線を当て、傾きを C_ij とする (対称化はしない)
- 応力は ASE の約束 (圧縮で負) にそろえている。DFTB+ 25.1 の detailed.out の応力の表は、対角の平均が同じファイルの Pressure と等しい
  向き (P = +tr/3) で書かれていたので、読むときに符号を反転する (`src/adit/outputs.py`)。この実際に実行して確かめた:
  e0 の対角 −1.389×10⁻⁴ au と Pressure −0.138911×10⁻³ au が同じ値。xx を 0.5 % 伸ばすと Pressure は −4.09 → −6.59 GPa、縮めると −1.50 GPa
- 最初の集計では、せん断の 2 個で Pressure (有効数字 6 桁) と表 (12 桁) の相対差 2.5×10⁻⁶ が向きの確かめの許容 (相対 10⁻⁶) を超えて止まった。
  許容を相対 10⁻⁴ にして集め直した

## 結果 (数値を並べるだけ。歪みが線形の範囲かは判断しない)

| C_ij [GPa] | 値 |
|---|---|
| C11 | 1133.34 |
| C21 = C31 | 196.05 |
| C44 | 638.81 |
| そのほかの与えた列 (C41、C51、C61、C14、C24、C34、C54、C64) | 0.00 |

直線の当てはめの残差の最大 0.037 GPa。歪みなしの Pressure は −4.09 GPa (格子を緩和していないため。当てはめの切片に入る)。
列 2、3、5、6 は歪みを与えていないので空欄。
