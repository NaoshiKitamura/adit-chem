# 既存入力の読み込み / Native input import

`adit.native_import.import_native(path, code=None)` は入力を読み取り、`NativeImportResult` を返す。`report()` は JSON に保存できる。入力ファイルは変更せず、計算・シェル・include は実行しない。ファイルの SHA-256、元の行番号と値、未知の指定、未対応の指定を記録する。

The reader returns a `NativeImportResult` with a JSON-serializable `report()`. It never edits inputs or executes calculations, shell commands, or includes. The report records file SHA-256 hashes, source lines and values, unknown fields, and unsupported features.

CLI は `adit-convert import 入力ディレクトリ 新しい点検先`。コードを自動判定できない場合も、点検先に `import_report.json` のみを残す。点検先を作れない場合は報告書も書けない。`--code vasp|qe|lammps|gromacs` でコードを明示できる。

Use `adit-convert import INPUT_DIR NEW_REVIEW_DIR` from the CLI. If the code cannot be identified, it still writes only `import_report.json` in the new review directory. No report can be saved when that directory itself cannot be created. Use `--code vasp|qe|lammps|gromacs` to specify the code explicitly.

| 入力 / Input | 対応範囲 / Supported subset |
|---|---|
| VASP | INCAR + VASP 5 POSCAR + 自動 Gamma/Monkhorst-Pack KPOINTS。一点計算、シフトなし。Single point, unshifted automatic mesh, explicit element names. |
| QE | `pw.in`、scf、ibrav=0、Å の CELL_PARAMETERS、Å/crystal の ATOMIC_POSITIONS、gamma/automatic K_POINTS。Plain unique element labels. |
| LAMMPS | `in.lammps` + 相対参照 data、明示した metal/real、atomic、p/f 境界、lj/cut、pair_coeff。`run 0` または下記の限定的な NVE/NVT MD。Masses の `# Si` のような元素ラベルが必須。`run 0` or the limited NVE/NVT MD subset below; masses are never used to guess elements. |

| GROMACS | `grompp.mdp` + `conf.gro` / `.pdb` + `topol.top`。積分法・ステップ・温度・圧力・カットオフを読み、トポロジーは解釈せず依存として記録する。The topology is recorded as a dependency, not interpreted. |

VASP の条件は ENCUT / EDIFF / NELM / ISMEAR / SIGMA / ISPIN / ALGO / PREC / LREAL / NELMIN / LASPH / LMAXMIX / NBANDS / ISYM。QE は ecutwfc / ecutrho / occupations / smearing / degauss / nspin / input_dft / conv_thr / electron_maxstep / mixing_beta と ATOMIC_SPECIES の擬ポテンシャル名を読む。

ADIT が生成した限定範囲の一点計算も読み込める。VASP の SYSTEM は題名として extra_incar に保持し、QE の tstress / tprnfor は出力フラグとして extra.control に保持する。QE の prefix / outdir / pseudo_dir は元の配置として `not_applied` に記録し、再生成先や擬ポテンシャル庫へ適用しない。これらの参照先を開くこともない。

Single-point inputs generated by ADIT within this subset can be imported. VASP SYSTEM is retained as an extra_incar title; QE tstress / tprnfor are retained as extra.control output flags. QE prefix / outdir / pseudo_dir are recorded in `not_applied` as source layout; they are not applied to regenerated paths or parameter libraries, and their referenced paths are never opened. Tests compare mapped fields, not whole-calculation equivalence.

未知の項目・未対応の構文があれば `spec` は `None` になり、読めた値を報告書に残す。下記の LAMMPS MD 以外の MD、構造最適化、固定・原子ごとの初速度、実行時変数、外部ポテンシャルへの参照推測は対象外。ファイルは 8 MiB、原子数は 10,000 まで。POTCAR は開かない。

Unknown or unsupported data blocks `spec`; successfully parsed values remain in the report. MD outside the LAMMPS subset below, relaxation, constraints, per-atom initial velocities, runtime variables, and inferred potential dependencies are unsupported. Limits are 8 MiB per file and 10,000 atoms. POTCAR is never opened.

返された Spec は確認用であり、元入力との同一性や実行可能性を保証しない。元にない Spec の値は `inferred_defaults` に列挙する。とくに擬ポテンシャル庫・POTCAR 名・実行条件は利用者が確認する。再生成は通常の検査を通す。

A returned Spec is for review, not a claim of identical regeneration or executability. Every Spec default absent from the source is listed under `inferred_defaults`. Review parameter-library settings, POTCAR names, and runtime settings before using normal validated project generation.

`complete=true` は限定された構文を読み込めたことだけを示す。`ready_to_regenerate` は常に false。QE の各 UPF と VASP の POTCAR 庫は `unresolved_dependencies` に元の行番号付きで列挙する。ファイル名が一致しても、その存在・内容・ライセンス・コピーは検証していない。

`complete=true` means only that the supported syntax was parsed. `ready_to_regenerate` is always false. Every QE UPF reference and the VASP POTCAR library appear in `unresolved_dependencies` with source lines. Matching names do not verify file existence, contents, licensing or copying.

LAMMPS は元の data を参照する確認用 Spec であり、別コードへの条件変換は外部 data の安全検査で停止する。LAMMPS drafts retain the original data-file reference; cross-code retargeting is blocked by the external-data safety check.

LAMMPS MD の追加範囲は、ADIT 生成器と全コマンド列が一致する atomic / lj/cut / 全方向周期系の NVE、および一定温度の Nosé–Hoover NVT。metal の時間 ps は fs に、real の時間 fs はそのまま共通 Spec に取り込む。初速度は `velocity all create T seed mom yes rot no dist gaussian` の温度・種と初期化方式を保持し、座標ごとの速度を推測しない。元 data の速度、継続計算、温度ランプ、追加の fix オプション、別の熱浴、NPT、原子群への部分適用は拒否する。型の元素は Masses の注釈、または生成した data 冒頭の明示的な `adit: atom types 1=Ar ...` から読む。

Additional LAMMPS MD support: atomic / lj/cut / fully periodic NVE and constant-temperature Nosé–Hoover NVT whose entire command sequence matches the ADIT generator. metal time in ps is converted to fs; real time already uses fs. The explicit generated Gaussian velocity initialization preserves temperature, seed, momentum removal and rotation settings; per-atom velocities are not invented. Data-file velocities, restarts, temperature ramps, extra fix options, other thermostats, NPT and partial atom groups are rejected. Explicit element labels may come from Masses comments or the generated data title. VASP and QE MD remain unsupported.

MD の根拠 / MD references: [LAMMPS velocity](https://docs.lammps.org/velocity.html), [units](https://docs.lammps.org/units.html), [fix nve](https://docs.lammps.org/fix_nve.html), [fix nvt](https://docs.lammps.org/fix_nh.html).

公式の根拠 / Official references: [VASP INCAR](https://vasp.at/wiki/INCAR), [KPOINTS](https://vasp.at/wiki/KPOINTS), [POSCAR](https://vasp.at/wiki/POSCAR), [QE INPUT_PW](https://www.quantum-espresso.org/Doc/INPUT_PW.html), [LAMMPS read_data](https://docs.lammps.org/read_data.html), [LAMMPS run](https://docs.lammps.org/run.html).
